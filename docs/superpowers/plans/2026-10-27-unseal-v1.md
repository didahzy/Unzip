# Unseal v1（解压核心）实现计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 交付 Unseal v1——无广告、纯离线的 Android 解压工具，支持 ZIP（含 AES/ZipCrypto/GBK 编码）与 RAR4/5（含密码与加密文件头）的极简三步流解压。

**Architecture:** 四模块：`:archive-core`（纯 Kotlin：模型、接口、魔数识别、路径安全、提取管线）、`:archive-zip`（zip4j 实现）、`:archive-rar`（unrar C++ + JNI 的 Android library，为未来 F-Droid lite flavor 可整体摘除）、`:app`（Compose UI + SAF 桥 + 会话编排）。压缩包先复制到 app cache 再操作（unrar 需要真实文件与随机访问）。

**Tech Stack:** Kotlin 2.2.10 / AGP 9.4.1 / Compose BOM 2026.02.01（跟随现有版本目录）、zip4j 2.x、unrar 官方 C++ 源码（rarlab unrarsrc，记录版本号）、DataStore Preferences、kotlinx.serialization、Navigation Compose。

**Spec:** `docs/superpowers/specs/2026-10-27-android-unzip-tool-design.md`（计划依据该规格，两者一起阅读）

## Global Constraints

- minSdk 26（脚手架从 23 提升）、targetSdk/compileSdk 37（维持现状）；`allowBackup="false"`
- 包名 `ziyao.huang.unzip` 不变；应用显示名 **Unseal**（`values/` 中文文案里显示「Unseal 启封」）
- 品牌蓝 `#2563EB`；浅/深双主题手工定义，不用动态取色
- 权限只允许：`FOREGROUND_SERVICE`、`FOREGROUND_SERVICE_DATA_SYNC`、`POST_NOTIFICATIONS`；**禁止 INTERNET 与任何存储权限**，文件访问一律 SAF
- 全部用户可见文案双语：中文默认 `values/strings.xml` + `values-en/strings.xml`，新增文案两份同任务提交
- 密码仅存内存（会话级），不落盘、不进备份
- unrar 源码仅用于解压；分发附带其许可文本（`THIRD-PARTY-NOTICES.md`）；**任何任务不得实现 RAR 压缩**
- zip slip 防护统一走 `:archive-core` 的 `SafePaths`，extractor 写盘前必调
- 所有 commit 用 Conventional Commits，结尾附 `Co-Authored-By: Claude Code <noreply@anthropic.com>`
- 单元测试不依赖 Android 设备（JVM 可跑）；native 路径用 connectedAndroidTest，无设备时跳过

```kotlin
package ziyao.huang.unzip.archive.core

enum class ArchiveFormat { ZIP, RAR, SEVEN_ZIP }

data class ArchiveEntry(val path: String, val isDir: Boolean, val size: Long,
                        val packedSize: Long, val encrypted: Boolean, val mtime: Long?)
// path 约定：'/' 分隔、无前导 '/'、不以 '/' 结尾

interface ArchiveSource { fun open(): InputStream; val size: Long }   // open() 每次返回新流

interface ExtractSink {
    fun createFile(path: String): OutputStream
    fun createDirectory(path: String)
    fun deletePartial(path: String)
    fun exists(path: String): Boolean
}

typealias PasswordPrompt = suspend (firstAttempt: Boolean) -> CharArray?   // null = 用户取消

data class ExtractProgress(val totalBytes: Long, val processedBytes: Long,
                           val currentFile: String?, val doneCount: Int, val totalCount: Int)

data class ExtractResult(val succeeded: List<ArchiveEntry>, val skipped: List<ArchiveEntry>,
                         val failed: List<ArchiveEntry>, val cancelled: Boolean)

interface ArchiveExtractor {
    suspend fun listEntries(source: ArchiveSource, password: PasswordPrompt): List<ArchiveEntry>
    suspend fun extract(source: ArchiveSource, sink: ExtractSink, entries: List<ArchiveEntry>,
                        password: PasswordPrompt, onProgress: (ExtractProgress) -> Unit): ExtractResult
}

object HeaderSniffer { fun sniff(header: ByteArray): ArchiveFormat? }   // 未知格式/字节不足 → null
class ArchiveRegistry(extractors: Map<ArchiveFormat, ArchiveExtractor>) {
    fun sniffFormat(header: ByteArray): ArchiveFormat?
    fun extractorFor(format: ArchiveFormat): ArchiveExtractor   // SEVEN_ZIP → 抛 UnsupportedOperationException
}
object SafePaths { fun isSafe(entryPath: String): Boolean }      // 见 Step 1 规则
class ArchiveFormatException(message: String) : Exception(message)          // 畸形/损坏压缩包
class PasswordCancelledException(message: String) : Exception(message)      // 加密文件头场景用户取消密码
```
